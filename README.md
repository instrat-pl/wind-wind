# Wind-wind
A win-win for energy modeller: a tool to compare different wind turbine profiles and methodologies.

Repositorium created for a presentation in OpenMod Workshop 2026 in Freiburg, Germany.

## Installation
Get uv (or any other Python manager as you wish).

**Linux**

    curl -LsSf https://astral.sh/uv/install.sh | sh

**Windows** 

in PowerShell, not cmd

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

then run any script or notebook. uv will deal with the installation on the first run.
